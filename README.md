# My-project-file

A simple to-do list website.

## Usage

Open `index.html` in any web browser — no install or build step needed.

- Type a task and press **Enter** (or click **Add**)
- Tick the checkbox to mark a task done
- Click **×** to delete a task
- Filter by **All / Active / Done**, or **Clear completed**

Tasks are saved in your browser (localStorage), so they stay after you refresh.
